# hm-icons Reference Copy

This repository contains a copy of the `hm-icons` project originally published by Human Made Limited.

Original repository:
https://github.com/humanmade/hm-icons

The package metadata in this repository identifies Human Made Limited as the original author and the code is distributed under its existing GPL v2 license.

## What the original project does

The project provides helpers for outputting inline SVG icons, including legacy fallbacks, and ships with Font Awesome assets.

## Why this repository exists

I kept this copy as a historical technical reference for reusable SVG icon helpers and asset-generation workflows.

I do not present the original implementation as my own work.

For source history, maintenance and upstream documentation, use the original Human Made repository linked above.
